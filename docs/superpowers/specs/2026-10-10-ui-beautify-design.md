# 积分系统 UI 美化设计规格

> 状态:已确认(2026-10-10)
> 范围:前端全部页面与组件;不改后端接口、不改业务逻辑
> 依据:6 镜头 UI 审查报告(60 条发现)+ 对抗式复核修正

## 1. 目标与约束

对「ORVIBO_员工积分系统」前端做一轮完整美化,同时满足两条硬约束:

1. **风格简约**:细边框、留白、无渐变无辉光、无 emoji 装饰、大圆角(>8px)禁止、多重阴影禁止
2. **工作高效**:操作路径短、点击少、高频操作可快速完成

已确认的决策:

| 决策点 | 结论 |
|--------|------|
| 美化范围 | 全部区域(操作台 / 发送记录 / 权限管理 / 弹窗 / 移动端) |
| 视觉基调 | B · 冷白清爽:近白底、冷灰层次,赤陶橙保留为唯一强调色 |
| 预览卡片 | B · 绿橙卡修正版:与实发飞书卡片所见即所得,修正对比度/等宽数字/字体栈 |
| 改动范围 | 样式 + 交互优化;不动后端接口 |
| 使用设备 | 桌面为主,移动端也常用 —— 响应式为一级优先 |
| 高频流程 | 记分发送(选人 → 加分/扣分 → 原因 → 预览 → 发送) |

| Token | 值 | 说明 |

## 3. 预览卡片:绿橙修正版(已决策)

保留 CardPreview 的绿橙实卡还原(用户选择所见即所得),做三处修正:

1. 扣分橙 `#ff9b20` → `#c65a00`(白字对比度达标)
2. 分数数字改 `--mono` + `tabular-nums`(当前是比例数字)
3. 字体栈改 `var(--sans)`(当前硬编码 `-apple-system` 绕过 token)

四色值 token 化为 `--card-plus / --card-plus-dep / --card-minus / --card-minus-dep`。不白卡化(方案 A 已否决),style.css 中 `.fk-*` 全套死代码删除(含审查补漏的 `.big`、`.fk-reason`)。

## 4. 第一批:换肤纠偏(视觉基建)

1. Token 全面切冷白(§2),替换全部暖米值;新增语义 token 并替换散落硬编码(`#D9775712`、`#EDF4EE`×2、`#F4E7E4`×2、modal 背板、account-panel 阴影)
2. 预览卡片绿橙修正版(§3)
3. style.css 基建整理:
   - 删死代码:`.fk-*` 全套、`.foot`、`.dot`、`.bot-tag`(全站零引用)
   - 合并重复选择器:`.brand` 两处、`.topbar-right` 两处
   - 合并重复媒体查询(420px 两处、640px 两处),统一按 820 → 640 → 420 排到文件尾部
   - 巨型行(第 2 行约 3KB)展开为一条规则一行,按 tokens / reset / 布局 / 操作台 / 记录 / 权限 / 弹窗 / 响应式分区注释
   - `!important` 清零(5 处全局 + 420px 断点 `.f-points input` 漏网 1 处,用更高特异性替代)
   - 组件样式归位:`DirectorySync` 的 `.sync-*` 与 `PeoplePicker` 的 `.picker-*` 移入各自 `<style scoped>`;`.chips/.chip` **保留全局**(App.vue 通知名单也在用,审查修正)
4. 字号最小 11px:全部 9-10px 上调(部门标签、人员路径、翻页按钮、状态标签、时间戳等);`.navigation>span{font-size:9px}` 降级规则删除
5. 弱化色对比度修复:文本用途的 `--faint`(≈2.7:1)换 `--muted`(≈4.0:1);`.count` 本身已是 muted,不动;`--faint` 只留给 placeholder
6. 圆角收敛:`.account-panel` 10px → 8px,删除头像 8px 覆盖(头像全站回组件自身 6px)
7. 同步更新 `design.md` 的 token 表,规格与代码保持一致

## 5. 第二批:动效与质感

1. **动效基线**:共享 0.12-0.15s 过渡(button / .person-option / .chip / .opt / .navigation button);补按下态 `button:active{transform:translateY(1px)}`、`.primary-button:active{background:var(--accent-deep)}`;`.history-item:hover` 补浅底 + 内缩 padding 的整行可点暗示
2. **进行中状态反馈**:主按钮 busy 态细线 spinner;同步中 / 撤回处理中等轮询态文字加 1.6s 半透明呼吸动画
3. **弹窗过渡**:三个弹窗 0.15s 淡入 + 上移 8px,背板单独淡入;**预览切换过渡不做**(审查结论:纯装饰、零收益)
4. **等宽数字全局化**:`tabular-nums` 从 `b,button,input` 提升到 body 级继承;时间戳 / 页次 / message_id 走 `--mono`
5. **间距 4px 网格**:7/9/13/15/17/23px 边距全部归入 `--sp-*`;`.panel` 的 24px 与字段 16px 不动
6. **信息分区**:
   - 历史列表 7 条 v-if 状态小字合并为一条 `.status-line`(失败/作废用 `--minus-ink`,处理中用 `--muted`)
   - 权限表加列头(姓名 / 状态 / 权限,11px 等宽弱化)
   - 确认弹窗原因包 `.reason-box`(浅灰块、细边框、限高滚动)
   - 发送结果宽模态加分区小标题;`.delivery-row` message_id 改全宽折行(取消 90px 内挤折)

## 6. 第三批:效率交互 + 移动端(围绕记分链路)

### 6.1 记分链路

1. **防抖自动预览 + 一键发送**:表单满足条件(已选人、原因已填、无警告)后 600ms 防抖自动刷新预览;预览有效时主按钮为「发送」直开确认弹窗。**保留「更新预览」按钮**(余额变化作废预览时它是唯一再生入口,必选不是可选);`makePreview` 内补原因/选人守卫
2. **通知范围同记分对象**:发送配置区加勾选,勾选后 recipients 实时镜像 targets、第二个选人器隐藏 —— 单人记分零选人
3. **记分对象全员模式**:给记分对象选人器接入已实现的 `allow-all`(部门批量记分从逐人勾选变为一次单选;`targetIds` 补 all 分支)
4. **表单分区 + 通知范围默认折叠**:操作台按「记分 / 发送配置」分两个 fieldset(等宽小标题);通知范围默认折叠为一行摘要
5. **部门筛选折叠 + 搜索自动聚焦**:三级部门下拉包进 `<details>` 默认收起;空层级隐藏;搜索框上移;选人器加 `autofocus`(记分对象实例开)
6. **快捷分值 + 最近原因 chips**:分值下加 1/2/5/10/20 chips(激活态沿用 `.f-seg` 语言),Shift+步进按 5 进位;原因框下展示最近 5 条原因(localStorage,单击填入)
7. **导航硬编码清理**:移除「· 基础分 60」,导航右侧只显示月份
8. **禁用原因可见**:主按钮下 `aria-live` hint 始终显示第一条未满足条件
9. **成功条自动消失**:成功条绿色语义 + 5s 自动收起(悬停暂停,错误条常驻)+ 就近滚动到视野
10. **键盘操作**:Esc 关弹窗(撤回确认优先);弹窗聚焦主按钮;Enter 提交;表单 Enter 触发预览。**所有非提交按钮补 `type="button"`**(防 click+submit 双触发,审查修正)
11. **历史加载态**:`loadingHistory` 区分「加载中…」与「还没有操作记录」

### 6.2 移动端专项

12. **底部固定操作栏**:≤820px 时「更新预览 / 发送」固定屏幕底部(安全区适配),长表单无需滚回顶部
13. **触控目标 ≥28px**:翻页等小按钮放大 padding
14. **最终总分两行网格**:`.balance-row` 改 grid,窄屏姓名与数字始终对齐、手动覆盖退第二行

## 7. 不做 / 延后(已决策)

| 事项 | 原因 |
|------|------|
| 发送记录搜索 | 后端分页无查询参数,纯前端过滤会假阴性(需后端配合,列为后续需求) |
| 权限批量授权 | 低频场景 + 需后端,列为独立功能需求 |
| 记住上次通知范围 | 误发风险,与既有防误发设计冲突 |
| 部门级联重构 | 折叠方案落地后观察使用率再评估 |
| 预览切换过渡动画 | 纯装饰、零收益 |
| 白卡化预览卡片 | 用户否决,选绿橙修正版 |

## 8. 必须保持的现状(实施红线)

- 语义色纪律:加分绿/扣分红只落在结果与激活态,不铺大面积
- 无障碍基线:focus-visible 轮廓、aria-label、disabled 态、role=alert
- 响应式断点 820/640/420 与双栏 1.1:0.9 + 预览 sticky
- 提交后智能重置(保留操作类型/分值/通知范围)、发送后自动开结果弹窗、预览 5 分钟校验、余额变化作废预览
- EmployeeAvatar 失败回退、空态覆盖、overflow-wrap 防撑破
- 本地打包字体(@fontsource),不引入外链、不引入新依赖、不引入重型样式方案
